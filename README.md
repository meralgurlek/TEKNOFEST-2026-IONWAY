# 🚤 TEKNOFEST-2026-IONWAY

## Electro-Hydrodynamic (EHD) Marine Propulsion System

IONWAY, geleneksel pervane sistemleri yerine  
Electro-Hydrodynamic (EHD) iyon itki teknolojisini kullanan  
yeni nesil sessiz deniz aracı prototipidir.

---

# 📌 Proje Amacı

IONWAY projesi;

- Sessiz deniz ulaşımı
- Çevre dostu su sistemleri
- İnsansız su araçları (USV)
- Akıllı göl ve rezervuar taşımacılığı

alanlarında kullanılabilecek yenilikçi bir sistem geliştirmeyi amaçlamaktadır.

---

# ⚙️ Özellikler

- Pervanesiz hareket sistemi
- Electro-Hydrodynamic iyon itki teknolojisi
- Sessiz çalışma
- Yağ sızıntısı olmadan çalışma
- Güneş enerjisi destek sistemi
- ESP32 akıllı kontrol ünitesi
- Modüler 3D yazdırılabilir tasarım

---

# 🔋 Teknik Özellikler

| Parametre | Değer |
|---|---|
| Voltaj | 24V – 48V |
| Güç Tüketimi | 10W – 45W |
| Tahmini İtki | 0.5 – 1.5N |
| Kontrol Ünitesi | ESP32 |
| Enerji Kaynağı | Li-ion + Solar |
| Gürültü Seviyesi | 0 dB Mechanical |

---

# 🧠 Sistem Çalışma Prensibi

1. Su, itki odasına girer  
2. Yüksek voltaj elektrotları su moleküllerini iyonize eder  
3. Elektrik alanı iyonları hızlandırır  
4. Hızlandırılmış akış çıkış nozülünden çıkar  
5. Oluşan ters itki aracı ileri hareket ettirir
